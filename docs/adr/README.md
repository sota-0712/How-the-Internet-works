# ADR（設計判断の記録）

「なぜこうしたのか」を、何か月か空けて戻ってきたときに思い出せるように残す場所です。
1件は A4 半分くらいで十分です。

## 書き方

- ファイル名は `NNNN-短い名前.md`（連番は4桁）
- 下のテンプレートをコピーして書く
- 決め直したときは元の ADR を消さず、ステータスを「置き換え済み（→ NNNN）」にして新しい ADR を足す
- まだ決まっていないことは「未決」と書いておく。それも判断の記録になる

### テンプレート

```markdown
# NNNN. タイトル

- ステータス: 提案 / 採用 / 置き換え済み（→ NNNN）
- 日付: YYYY-MM-DD

## 背景

何に困っていたか、どんな制約があったか。

## 決定

何をどうすると決めたか。

## 検討した他の案

- 案: 選ばなかった理由

## 影響

この決定で楽になること、気をつけること、見直すきっかけ。
```
